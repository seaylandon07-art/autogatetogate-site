# autogatetogate.com

Website for GateToGate, an autopilot add-on for Microsoft Flight Simulator 2024.

Static site: `index.html` plus the scroll-driven film frames in `frames/`.
Served with GitHub Pages at https://autogatetogate.com

Aircraft model in the film: "A320neo" by pranav27 (CC BY 4.0), modified.

## Launch day: turn on the buy button

In `index.html`, inside `<div class="buy">`, swap the dimmed "Coming December 1" span for the commented-out Gumroad link above it, and un-comment the `gumroad.js` script near the end of the page. Then set the product back from sold out in Gumroad.
